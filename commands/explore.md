description: Plan and run a time-boxed exploratory testing session
argument-hint: "[area, feature, or URL]"
---

Run an exploratory testing session on: $ARGUMENTS

Use the `exploratory-testing`, `usability-testing` and `bug-reporting` skills.

1. Write a charter: "Explore <area> with <resources> to discover <information>". Time-box it to 30-60 minutes.
2. Use SFDIPOT heuristics and testing tours; vary data, roles, order of actions, interruptions and environment.
3. Keep session notes (what was tried, what was seen, questions, risks), then list bugs and improvement ideas.
4. File bugs in the `bug-reporting` format and finish with a debrief: coverage, confidence, next charters.
