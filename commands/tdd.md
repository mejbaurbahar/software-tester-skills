Build with TDD: $ARGUMENTS

Use the `tdd-workflow` and `unit-testing` skills.

1. Write a short test list of behaviors and edge cases; pick the simplest first.
2. RED: write one failing test and run it to confirm it fails for the expected reason.
3. GREEN: write the least code that passes. REFACTOR with the tests green.
4. Repeat one cycle at a time, showing the red and green runs. Commit-sized steps only.
